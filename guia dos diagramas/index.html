Guia de ícones AWS para diagramas no Draw.io

Material de apoio para reconhecer os principais componentes de uma arquitetura AWS no diagrams.net/Draw.io. Os ícones abaixo são os ícones oficiais da AWS (biblioteca "AWS17" incluída no Draw.io); onde a AWS não usa um ícone quadrado — casos de VPC, Availability Zone, sub-rede e Security Group — o guia mostra a convenção real de contorno tracejado usada nos diagramas oficiais.

Atenção metodológica: este guia deve ser disponibilizado somente quando a equipe decidir que ele não interfere no experimento. Se os participantes receberem o guia antes da tarefa, ele pode influenciar as escolhas e reduzir a validade da comparação. A aula e o enunciado não devem entregar a solução esperada.

Como habilitar a biblioteca

No Draw.io, abra More Shapes, localize a categoria Networking, marque a biblioteca AWS e selecione Apply. A documentação do Draw.io descreve a biblioteca AWS e o uso de conectores, grupos e rótulos. A página oficial da AWS também disponibiliza os pacotes de ícones aprovados, organizados em ícones de serviço (quadrados), ícones de recurso e ícones de grupo (contornos tracejados).

Rede e isolamento

Nem todo elemento de rede tem um ícone de serviço quadrado. VPC, Availability Zone, sub-redes e Security Group são ícones de grupo na biblioteca oficial da AWS: contornos tracejados que envolvem outros ícones, não emblemas coloridos isolados. É assim que eles aparecem de fato no Draw.io.

Estrutura típica de contenção em um diagrama de rede AWS — cada nível é desenhado como uma caixa tracejada rotulada, e os serviços ficam dentro dela:
